# IF : SURVIVE 戦国・幕末異聞

和風モダンな歴史 IF ビジュアルノベルシリーズ『**IF : SURVIVE 戦国・幕末異聞**』のマルチタイトル共通エンジン（Godot 4.6 / GDScript / `1920x1080`）および第1弾『**本能寺・残照録 〜天正十年、その先の覇王〜**』のリポジトリです。

## 主な実装機能

- **3段階ナビゲーション**: メインタイトル（ロゴ中心）→ シリーズ選択画面 → 各作品タイトル画面・本編
- **マルチエピソード管理 (`GameManager`)**: [episodes/catalog.json](episodes/catalog.json) に基づく作品切替・アセットパス自動解決
- **周回・QoL 機能 (`SaveStore` / `QolOverlays`)**:
  - エピソード別のセーブ／ロード（急速記録＋記録帳 3 スロット）およびシリーズ共通環境設定
  - 既読スキップ（未読箇所での自動停止）、Ctrl 押し続けスキップ
  - 歴史年表（到達済み章からのリプレイ＆未回収終幕ヒント付き分岐表示）
  - シリーズ終幕録（全作品のエンディング達成状況と再鑑賞機能）
  - バックログ（ホイール上回転 / `H` キー）
- **演出システム**: 立ち絵差分クロスフェード、SE／フラッシュ連動立ち絵アクション、句読点ウェイト付き文字送り、BGM 連動ビネットシェーダー、2層環境パーティクル（火の粉・雨・朝霧・月光・陽光・塵）

## 操作方法（本編）

| 操作 | 機能 |
| :--- | :--- |
| 左クリック / `Space` / `Enter` / `Z` | テキスト送り・次の行へ進む |
| `H` / マウスホイール上 | 語り履歴（バックログ）を開く |
| `A` | 自動送り切替 |
| `S` / `Ctrl` | スキップ（未読で自動停止） |
| `Q` / `F5` | 急速記録（クイックセーブ） |
| `L` / `F9` | 急速再開（クイックロード） |
| `M` / 右クリック | メッセージ枠の非表示／再表示 |
| `Esc` | 戻る／確認 |

```text
    ├── 02_ryoma/              # 第2弾 格納枠
    └── 03_yoshitsune/         # 第3弾 格納枠
```

## 起動方法

1. **Godot Engine 4.6**（4.3 以降の `GL Compatibility` 対応版）を用意します。
2. [project.godot](project.godot) を Godot プロジェクトマネージャーからインポートして実行（`F5`）してください。
